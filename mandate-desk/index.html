Mandate Desk

Which expense lines may the agent clear alone?

Prototype on synthetic data. Built independently by Russell Harris; not affiliated with or endorsed by Sanity and does not describe Sanity's systems. Every company, person, policy value and figure is invented. Nothing persists after reload.

Queue () Canon and mandate Evals () Audit and access Measures Spec pack

A review agent on a synthetic expense batch. It clears a line on its own only when the line is in policy under exactly one approved policy fact and inside a written dollar mandate. Every other line goes to the manager, the submitter, procurement or the policy owner with the fact and the figure. Policy facts and the mandate change only through a change request that previews its impact and passes the evals before the owner signs it.

Canon and mandate

Prototype on synthetic data. Built independently by Russell Harris; not affiliated with or endorsed by Sanity and does not describe Sanity's systems.

The approved policy facts the agent reads (owner: Controller) and the mandate that limits what it decides alone (owner: CFO). Both change only through a change request. Opening one previews which lines will change, which would have changed if it applied to the whole period, and how many are protected, then reruns all 17 evals under the proposed canon. Only the owner role sees Sign, and Sign stays disabled while any eval fails.Context layers: Canon is the approved facts; Process is the mandate.

Evals and release gate

Prototype on synthetic data. Built independently by Russell Harris; not affiliated with or endorsed by Sanity and does not describe Sanity's systems.

E01 to E17 run on load and after every change, against a hand-written answer key. The same checks, plus scenario checks and an independent Python implementation, run in Node before every publish. Pick a simulated code fault to see the gate block it. The queue above always runs the released code; a blocked version cannot ship.

Audit and access

Prototype on synthetic data. Built independently by Russell Harris; not affiliated with or endorsed by Sanity and does not describe Sanity's systems.

An append-only event list for this session: every outcome the agent assigns, every human action, preview, refusal and signature, with the canon version and a SHA-256 hash of the line facts, the fact versions used, the mandate values and the outcome. Replay recomputes each event under its logged canon version with the code version selected in the evals section.

The register toggle simulates an outage. With it off, a claimed pre-approval cannot be verified, so the agent defers instead of trusting the claim (M5).
